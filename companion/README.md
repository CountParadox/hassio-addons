# Bitfocus Companion add-on for Home Assistant

Runs [Bitfocus Companion](https://bitfocus.io/companion) on Home Assistant OS
or Supervised, using the official Companion container image.

- Supports `amd64` and `aarch64`.
- Tracks the latest stable Companion release automatically.
- Data is kept in the add-on config folder and included in backups.

See [DOCS.md](DOCS.md) for setup, ports and notes on USB surfaces.

Companion is developed by [Bitfocus AS](https://bitfocus.io) and released under
the MIT licence. This add-on only packages it.
